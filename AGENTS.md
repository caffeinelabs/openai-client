# AGENTS.md

A Motoko client library for a curated subset of the OpenAI REST API, distributed as a [mops](https://mops.one) package named `openai-client`.

## Generated code

The entire `src/` tree is generated by [OpenAPI Generator](https://openapi-generator.tech) (generator version in `.openapi-generator/VERSION`). Do not hand-edit files under `src/`; regeneration will overwrite them. The full list of generated paths is tracked in `.openapi-generator/FILES`, and `.openapi-generator-ignore` controls which files the generator leaves untouched.

Only the APIs listed under "API Subset" in `README.md` (Chat, Completions, Models, Embeddings, Images, Audio, Moderations, Files) are shipped; other OpenAPI operations are pruned, with models kept only transitively.

## Layout

- `src/Apis/` — one module per included API group.
- `src/Models/` — generated request/response types.
- `src/Config.mo` — `defaultConfig` and shared client configuration.

## Toolchain

The Motoko compiler version is pinned in `mops.toml` under `[toolchain]` (`moc = "1.4.1"`). Dependencies and their versions are declared in `mops.toml` and locked in `mops.lock`; only `mops.toml` and the `[package].files` glob there determine which files are published.

## Dependencies

Dependencies are managed with mops; `.mops/` is a local dependency cache and is git-ignored.

This repository contains no test, lint, or format scripts, no Makefile, and no CI workflows — it is a generated package, so changes come from regenerating `src/` rather than editing it by hand.
